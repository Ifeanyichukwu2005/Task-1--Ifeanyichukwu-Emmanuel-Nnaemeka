Data Cleaning and Preparation

Project Overview
This project is part of my first data analytics task with DecodeLabs. It focuses on preparing a dataset for further analysis using Microsoft Excel.

Tools Used

- Microsoft Excel

Project Activities

- Checked records for duplicates.
- Checked the uniqueness of order IDs.
- Identified blank values in the dataset.
- Standardised date formatting.
- Checked numeric values for invalid entries.
- Verified that TotalPrice matched Quantity multiplied by UnitPrice.
- Reviewed consistency in payment methods, order statuses, product categories, and product names.
- Documented data quality checks and findings in a change log.

Key Findings

- No duplicate records were identified during the duplicate-record check.
- Order IDs were verified as unique.
- The date range observed was January 1, 2023, to June 30, 2025.
- A total of 309 blank cells were identified in the CouponCode column and flagged for review.
- Some CustomerID values appeared more than once and were flagged for further review.

Lessons Learned

This project helped me understand the importance of checking data quality, validating numerical relationships, documenting changes, and investigating unusual values before making assumptions.

Project Status

Initial data cleaning and validation checks have been documented. The blank CouponCode values and repeated CustomerID values require further review before the dataset can be considered fully validated.
